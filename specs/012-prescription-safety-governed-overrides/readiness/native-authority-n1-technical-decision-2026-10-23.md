### Competing paths: conditional design and actual fail-closed boundary

This is non-executable protocol pseudocode, not a new implementation API. The unresolved primitive is deliberately explicit; execution cannot proceed past it today.

```text
F012 guarded decision/sign (future implementation only):
  verify JWT and bind native subject/session/person/action/facility/purpose
  BEGIN one authoritative PostgreSQL transaction, READ COMMITTED
  acquire A-DB admission; acquire exact idempotency scope
  require NAC-1 admitted for the pinned Auth topology
    if not admitted: ABORT before any dependent successful effect or disclosure
  acquire NAC-1 native protections in its accepted total order   [MISSING BINDING]
  fresh native + local restriction + clock checks after waits
  acquire producer/domain/local authority locks in accepted merged order
  if receipt exists: current disclosure check; return original authorized receipt, no effects
  for a new effect: fresh source, S4/P1/P2/independence, evidence digest and aggregate CAS checks
  evaluate all current deadlines immediately before conditional domain write
  conditional decision/sign = logical action point; retain all protections
  atomically append required signature/lineage/P3/obligation/audit/outbox/receipt
  recheck applicable deadlines; COMMIT or ROLLBACK everything new

Native invalidation/revocation (provider path, not implemented by this artifact):
  HTTP request begins; this alone gives no F012 ordering guarantee
  BEGIN native transaction under the pinned native contract
  acquire NAC-1 conflicting authoritative resources in proven native order [UNKNOWN]
  re-read and apply native-defined invalidation, factor/user/family/session changes
  COMMIT native invalidation = writer serialization point
  respond HTTP; SHIFAA appends/reconciles local workflow/audit as contracted
  on timeout/partial response: do not infer native rollback; reconcile authoritative state
```

FOR SHARE of an existing session would order only a native UPDATE/DELETE of that session. Until all missing resources/predicates/order are established, the two paths have **no proven common serialization boundary**. Local recovery restriction before HTTP is useful denial intent, but cannot be claimed to order every native writer. Separate services sharing a database is insufficient evidence without their actual write/lock contract.
