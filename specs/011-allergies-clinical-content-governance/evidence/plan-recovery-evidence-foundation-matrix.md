## Seven-operation cross-layer closure

All trusted inputs are native/session verified; public payloads are untrusted. Read projections use final current authorization. All five mutations share unchanged atomic receipt protocol: domain + audit + outbox + encrypted canonical receipt + completed idempotency ONE transaction; failed attempt no partial effect, same-key authorized replay original tuple, unknown commit settled scope before new attempt. External preparation is outside locks; only bounded local receipt AES-GCM is inside. Exact ranks are model §11, including FK parents before audit.
